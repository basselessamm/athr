### 📖 Overview
**ATHR (أَثَر)** is a minimalist, offline-first Islamic productivity application designed to help users engage with religious texts in a meaningful way. Unlike traditional apps, ATHR focuses on the "ripple effect" of good deeds, encouraging users to capture insights and return to them consistently.

### ✨ Key Features
- **💎 Premium Mushaf Experience:** High-quality Quranic text with a realistic page-flip effect and precise verse-level interaction.
- **🧵 Threads of Return:** A unique system to "capture" verses or hadiths and create personal threads for reflection and future action.
- **📡 Offline-First Architecture:** Full access to Quran, Tafseer, and Azkar without requiring an internet connection.
- **🛡️ Privacy by Design:** No tracking, no cloud sync, and no ads. Your spiritual journey remains private on your device.
- **🎨 Modern RTL UI:** A clean, calm, and responsive interface built specifically for the Arabic language.

### 🛠️ Tech Stack
- **Framework:** Flutter
- **State Management:** Riverpod
- **Database:** Drift (SQLite)
- **Navigation:** GoRouter
- **Notifications:** Flutter Local Notifications

### 📥 Getting Started
You can download the latest version of ATHR from the [Releases](https://github.com/basselessamm/athr/releases) page.

#### For Developers:
1. Clone the repository:
   ```bash
   git clone https://github.com/basselessamm/athr.git
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run --release
   ```
